# LinkinNotes 四象限浮窗

适用于 Windows x64 的好用便签四象限桌面浮窗，使用 Tauri、React 和 Python 开发。读取全部未完成待办，并通过客户端本地同步队列双向同步。

## 下载与首次连接

1. 在 [Releases 发布页](https://github.com/AkrenChen/LinkinNotes/releases/latest)的 Assets 中下载 `LinkinNotes-版本号-portable.zip`。仓库首页的 **Code → Download ZIP** 下载的是源码，不能直接双击使用。
2. 将便携包完整解压到一个固定目录，保留 `LinkinNotes.exe` 和旁边的 `sidecar` 文件夹。使用便携包不需要安装 Python、Node.js 或 Rust。
3. 打开好用便签 **Windows 客户端**，登录你自己的账号，并等待客户端加载完数据。
4. 运行解压目录中的 `LinkinNotes.exe`。浮窗会自动识别本机已登录账号，显示该账号全部未完成的四象限待办，不限制月份。
5. 如果暂未连接成功，保持好用便签运行，稍等后点击浮窗顶部的刷新按钮；具体错误会显示在窗口底部。

**无需在浮窗里再次登录，也不需要填写接口地址、手动选择数据库或导入他人的配置。** 程序使用你自己电脑上已登录客户端的数据，未绑定开发者账号。数据库密钥仅在内存中读取和使用，不保存账号密码或明文数据库。

## 日常使用

| 操作 | 使用方法 |
| --- | --- |
| 新建任务 | 点击对应象限右上角的 `+`，直接在象限内输入 |
| 编辑任务 | 点击已有任务文字，原位编辑 |
| 保存 / 换行 / 取消 | `Enter` 保存，`Shift+Enter` 在文字中换行，`Esc` 取消；编辑框右侧 `×` 也只取消编辑 |
| 连续新建 | `Ctrl+Enter` 保存当前任务并在同一象限继续新建，自动聚焦；此功能从 0.3.12 起提供，使用前请核对下载版本 |
| 完成任务 | 点击任务左侧勾选框，完成后从未完成列表移除 |
| 切换象限 | 右键任务或输入行，在菜单中选择目标象限 |
| 删除任务 | 右键已有任务，点击“删除待办”；立即删除并同步，**没有二次确认** |
| 窗口操作 | 拖动顶部移动窗口；顶部按钮可切换置顶、最大化 / 还原、隐藏 |
| 显示 / 隐藏 | 默认全局快捷键为 `Ctrl+Alt+Q`，可在设置中修改；窗口在前台时隐藏，否则唤起 |
| 找回隐藏窗口 | 应用不显示 Windows 任务栏图标；可使用快捷键，或从系统托盘菜单选择“显示四象限” |
| 退出程序 | 从系统托盘菜单选择“退出”；窗口右上角隐藏按钮不会退出程序 |

左上角三横杠打开设置，可修改快捷键和四个象限名称，点击“保存设置”生效。象限名称只影响浮窗显示。设置保存在当前 Windows 用户目录，重启后保留；快捷键被占用时会提示，可更换组合键。

### 同步说明

- 保存、移动、完成和删除会写入好用便签的本地数据库及同步队列，再由好用便签客户端继续同步到云端，因此使用时请保持客户端运行。
- 浮窗每两秒读取客户端变化。“等待同步”表示客户端队列尚未处理完成，不代表修改没有保存，也不代表已经上传云端。
- 保存失败时保留输入。遇到客户端同时修改的冲突时，核对内容后再采用最新版本，避免覆盖真实变更。
- 在好用便签中切换账号后，等待浮窗刷新，再重新打开任务编辑框。

### 跟随好用便签启动

此功能默认关闭。在设置中打开“跟随好用便签启动”并点击“保存设置”后，程序会配置当前用户的 Windows 登录启动项：登录 Windows 后静默监听，检测到好用便签启动时自动打开浮窗，约每两秒检查一次。

手动退出浮窗后，不会反复拉起，等好用便签下次启动再联动；关闭好用便签不会退出浮窗。关闭设置开关并保存会撤销登录启动项并停止监听。开启后请保持完整程序目录位置不变。

### 更新版本

先从系统托盘菜单退出旧版，再解压并运行新版，勿只替换单个 EXE 或丢弃 `sidecar` 文件夹。开启联动后，运行新版会更新启动目标路径；移动目录后请运行新位置的程序并保存设置。用户设置独立于程序目录存放，无需复制别人的配置文件。

## 适配范围与连接排查

- **系统：** 当前提供 Windows x64 便携版，需要 WebView2 Runtime；不适用于 macOS、Linux 或仅安装手机端 / 使用网页端的情况。
- **客户端版本：** 当前适配好用便签 **Windows 8.0.5** 的本地数据库结构。其他版本尚未验证；客户端更新导致结构变化时，需要重新适配。
- **数据位置：** 当前按 `%USERPROFILE%\haoyongbianqian\data` 查找数据库。客户端安装目录无需与开发者相同，但迁移了数据目录的用户可能无法连接，当前没有手动选择目录功能。
- **账号识别：** 需能唯一识别一个已登录账号。遇到无法确定账号的提示时，请只保留一个已登录客户端后刷新；程序不会让用户手动输入密钥。
- **任务类型：** 富文本 / 附件任务可调整象限，内容请在原客户端编辑；重复任务请在原客户端完成，以保留后续提醒。

| 现象 | 检查方法 |
| --- | --- |
| 提示先打开并登录好用便签 | 确认 Windows 客户端正在运行且已登录，待数据加载完成后点击刷新 |
| 提示无法确定账号或数据未就绪 | 只保留一个已登录客户端，稍等后刷新；同时核对数据目录是否为上述默认位置 |
| 无法读取数据库或访问进程 | 核对客户端版本、数据位置和 Windows 权限，保留窗口中的完整错误信息以便排查 |
| 快捷键无反应 | 先从托盘显示窗口，检查设置及快捷键注册错误；尝试其他组合键。若整个程序无响应，退出旧版后重新运行 |
| 一直显示等待同步或同步失败 | 检查好用便签客户端本身的网络和同步状态；浮窗依赖客户端处理云端同步 |

反馈问题时请提供浮窗版本、好用便签版本、操作步骤和错误文字；不需要提供账号密码、密钥或个人数据库。

## 从源码构建

需要 Windows x64、Node.js、Rust MSVC 工具链、Visual Studio C++ Build Tools、Python 3.12 和 WebView2 Runtime。

```powershell
npm ci
python -m pip install -r backend/requirements.txt
./build.ps1
```

构建脚本从上游下载并校验固定版本的原生依赖，运行后端测试，再打包前端、原生窗口和 Python sidecar。输出位于 `release/LinkinNotes/`。

单独运行检查：

```powershell
python scripts/fetch_native_dependencies.py
python -m unittest discover -s backend -v
npm run build
cargo test --release --manifest-path src-tauri/Cargo.toml
```

测试在临时目录创建纯虚构数据库，覆盖中文内容、索引触发器、冲突拒绝、不按月份过滤、删除同步队列及事务/索引回滚，不读取或修改真实待办。

## 数据与实现

- 通过当前用户已登录的好用便签进程确定账号和数据库，仅在内存中读取并使用数据库密钥。
- 修改使用 SQLite 原生事务，并写入 `operations_v1`，由好用便签客户端继续同步。
- 用户配置保存在 `%APPDATA%/local.linkin.notes/preferences.json`，不包含在仓库中。
- 本项目是独立的第三方工具，与好用便签官方无隶属关系；请仅连接自己有权访问的账号和数据。

原生依赖版本、下载来源及许可链接见 [THIRD_PARTY.md](THIRD_PARTY.md)。仓库不包含第三方 DLL、个人待办数据库、研究记录或已编译程序。
